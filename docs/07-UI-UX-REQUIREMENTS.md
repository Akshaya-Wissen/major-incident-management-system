# UI/UX Requirements

## Design Direction

The application should feel like an operations command center: dense, scannable, calm, and action-oriented.

## Pages

- Login: demo admin credential form
- Dashboard: incident metrics, workflow load, recent incidents
- Incident Board: lifecycle columns and incident creation
- Incident Details: roles, impact, action forms, and timeline
- RCA: resolved/RCA/closed incidents requiring post-incident attention
- Knowledge Base: searchable runbooks and article creation

## Interaction Requirements

- Use badges for severity and status.
- Use compact cards for incidents.
- Keep workflow forms close to the incident detail context.
- Show API errors in-page.
- Keep mobile navigation usable without hiding key workflows.
